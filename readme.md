## About The Project


I've always enjoyed being able to listen to music with friends but there has never been a good way to do so. Spotify groups are weird and every discord music bot, either stutters, finds the wrong songs, or just flat out don't work. That's why I've made my own with some new features

Features:
- Search cleaning: Every search is first routed through spotify to get a clean serach for youtube that will find the correct song
- Song downloading: Instead having songs stream directly from youtube, each request is first downloaded to limit lag and stuttering 
- And more to come (see <a href="#roadmap">Roadmap</a>):

## Usage

Commands (/command):
- Play: Play a song / add it to the queue
- Queue: View the queue
- Remove: Remove a song from the queue
- Clear: Clear the queue

<br>

UI: 
- Pause: Pause playback
- Resume: resume playback
- Stop: Stop playback

<br>

Env Variables:
- SPOTIFY_CLIENT_ID
- SPOTIFY_SECRET
- DISCORD_GUILD_ID
- YOUTUBE_API_KEY
- BOT_TOKEN
